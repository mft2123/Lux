# Lux 视觉验收清单（2026-10-23）

服务端能验的（库、条目数、目录链、sidecar）今天都已经用接口和 SQL 验过了，**这份清单只验浏览器里看得见的东西**，
重点是今天动过的三处：目录下钻、`影视原盘` 库、`晚会` 库。

## 0. 打开方式

- 地址：**http://192.168.8.8:8099**（测试容器 `lux-testlib`，8099 → 容器 8097）
- 账号：`admin` / `Test@12345a`
- **先按一次 Ctrl+F5**：今天换过镜像，旧的 JS bundle 可能被缓存，硬刷能避免把缓存问题当成 bug。
- 建议窗口：1440 宽（桌面）；手机上只看「库列表 + 一个库根层」即可，不做硬性要求。

## 1. 库列表页

打开 `/libraries`，应该看到 **10 个库**：

| 库名 | 备注 |
| --- | --- |
| 电影 / 电视剧 / 动画 / 综艺 / 纪录片 / 演唱会 / 晚会 | 7 个板块库 |
| **影视原盘** | remux 专用库，中文名（不是 `REMUX`） |
| **国产短剧** | AI 短剧专用库，由 `待整理/国产短剧/` 手动归板 |
| 合集 | 内置全局合集库，0 条目 |

- [ ] 名称都是中文/正确，没有出现 `REMUX` 这种目录名
- [ ] 每个库卡片能正常显示（封面或占位图不报错）
- [ ] 点进任意库不报「媒体库不存在」

## 2. 电影库（本次改动的核心）

预期：**根层只有一个文件夹「国外」**，不是 5 张电影卡片平铺。

- [ ] `/libraries/<电影>` 根层：**1 项** = `国外`
- [ ] 点「国外」→ 出现 `1980s` / `2000s` / `2010s`（3 项）
- [ ] 点 `2010s` → `机械姬 (2014)` / `速度与激情：特别行动 (2019)`（2 项）
- [ ] 点任一影片目录 → **1 张电影卡片**（如「机械姬」），不是空页面
- [ ] 页头出现「返回上一级」，点它能逐级退回根层
- [ ] 根层的「目录」下拉筛选存在；**进入子目录后该下拉消失**

> 若根层直接平铺 5 部电影：说明页面没带 `parentId=root`，先 Ctrl+F5；仍如此则前端没生效。
> 若点「国外」提示「此文件夹没有可浏览内容」：说明可见性判定没生效。

## 3. 电视剧库

预期：根层就是 **19 部剧的卡片**（剧集是扁平的，没有地区/年代目录，这是设计如此）。

- [ ] root = 19 项，能看到「20:23」「假面骑士ZZZ」「刑事侦缉档案4」等
- [ ] 点「假面骑士ZZZ」进详情页，Season 01 / 第 45 集存在（这是今天从特摄剧迁过来的）
- [ ] 页头「19 项内容」，没有「返回上一级」（本来就在根层）

| 演唱会 | 1 项：`国内` 文件夹 → 点进去是「周华健96 香港弦全演唱会」 |

- [ ] 动画根层混排（剧集 + 文件夹）能正常显示，文件夹可点进去
- [ ] 纪录片 `国内` 可点进去 → 年代目录 → 片名 → 条目
- [ ] 演唱会 `国内` 可点进去 → 直接是 1 部演出（无年代层）
- [ ] 综艺点进去能开详情

- [ ] 根层 1 项：`2026年中央广播电视总台春节联欢晚会 (2026)`（一个文件夹，无地区层、无年代层）

## 6. 影视原盘库（今天新建，最需要看）

预期：根层 2 项 —— 一个剧集卡片 + 一个 `电影` 文件夹。

- [ ] 根层 = `假面骑士ZZZ`（剧集）+ `电影`（文件夹）
- [ ] 点 `电影` → `国外` → `2000s` → `斯巴达300勇士 (2006)` → **1 张卡片「斯巴达300勇士」**
      （这是 300KB 的假 remux 文件，卡片能出来就说明链路通了）
- [ ] 这条链上每一层都能用「返回上一级」退回
- [ ] 库名是「影视原盘」，不是 `REMUX`

## 6.5 国产短剧库（今天新建）

预期：根层 3 项 —— 两个剧集卡片 + 一个 `2020s` 文件夹。

- [ ] 根层 = `AI短剧甲`、`AI短剧丙`（两个剧集）+ `2020s`（文件夹）
- [ ] `AI短剧甲` 点进去有 Season 01 / 2 集
- [ ] `AI短剧丙` 点进去有 Season 01 / **3 集**（第1集/第2集/第3集）——这条验证的是镜像改写集号
- [ ] `2020s` → `AI短剧乙 (2025)` → 1 张卡片「AI短剧乙」
- [ ] 库名显示「国产短剧」，不是空库

> 三条都是 150KB/120KB/80KB 的合成样本，没有海报是正常的。

## 7. 空状态与异常

- [ ] `合集` 库：显示「当前没有可见的合集。」之类的空状态，不是白屏或报错
- [ ] 浏览器控制台（F12）没有红色报错；有的话记下来
- [ ] 刷新任意库页面，排序/筛选选择不丢

## 8. 明确不用验的

- 管理后台、扫描任务页、归档设置页（今天没动）
- 播放功能（测试库里是假文件，播放必失败）
- Emby 客户端兼容性（另说）
