# 自动入库：按媒体目录自动建库 + 自动扫描

> 状态：**已实现**（2026-10-21），代码 `src/application/archive/auto_library.rs`，
> 规范已并入 `docs/archive-pipeline.md` §5.6。
>
> 原始缺口（2026-10-20 实测）：115 `媒体目录` 下有 `电影/电视剧/动画`，本地镜像库
> 只有 `电影/电视剧`，而 Lux 只注册了一个库（`name=电影, kind=MOVIE`）。
> 结果 web 只显示电影，电视剧/动画永远不会出现——因为没有任何库指向它们。

## 1. 规则表

目录第三层是**年代**（`2010s`/`2020s`，见 `docs/archive-pipeline.md` §4）。

| 媒体目录分类 | 自动创建的库 | kind | 根路径 |
| --- | --- | --- | --- |
| `电影` | 电影 | MOVIE | `<mirror_root>/电影` |
| `电视剧` | 电视剧 | SERIES | `<mirror_root>/电视剧` |
| `动画/国内` | **国内动画** | MIXED | `<mirror_root>/动画/国内` |
| `动画/国外` | **国外动画** | MIXED | `<mirror_root>/动画/国外` |
| `晚会` | 晚会 | SERIES | `<mirror_root>/晚会` |
| `演唱会` | 演唱会 | SERIES | `<mirror_root>/演唱会` |
| 其它一级分类 | 同名 | 含「电影」→ MOVIE，否则 SERIES | 同名目录 |

用户已确认（2026-10-21）：

- **动画和动漫合并成一个板块**，只按地区分「国内 / 国外」，不再按产地分板块；
  归类器只输出 `动画`；
- **动画板块按地区拆库**：`动画/国内` → 库「国内动画」，「国/外」各一个库；
- 地区名兼容多套写法（`国内/国产/华语/大陆/内地/港台` → 国内，
  `国外/日本/日韩/欧美/韩国/海外` → 国外）；同一地区的多个子目录合并成一个库的多个根；
- `动漫` 目录当作同一板块的别名（`动漫/日本动漫` 也喂给「国外动画」，不另建库）；
- 动画板块的库类型是 **MIXED**：板块里既有动画电影也有番剧，按文件逐个判定；
- **年代段与既有 `影视库/媒体目录` 一致**；**建库后自动全量扫描**。

## 2. 触发点（三个）

1. **归档 run 结束**：本轮 `organized` 非空 → 立即对账，新建的板块立刻有库并入扫描队列。
2. **启动对账**：进程启动即跑一次，把 `media` 一级子目录与已注册库比对，补建漏掉的
   （覆盖历史数据、以及进程在两次之间挂掉的情况）。
3. **兜底周期对账**：每 600 秒一次，覆盖「目录从 Lux 之外多出来」（手工整理、别的工具写入）。

## 3. 幂等与安全

- 幂等键 = **库根路径**：已存在的根不再建库；只补该库缺的根（`updated`）。
- 只处理 `mirror_root` 的**一级子目录**，不递归；动画板块再往下认一层地区目录。
- 板块没有任何地区子目录时，整块作为一个库（不会把年代目录当库）。
- 板块下既不表地区、也不独立的子目录（如 `儿童动漫`）保留自己的库，避免标题不可见。
- 目录下没有任何 strm/nfo 时**不建库**，避免产生空库。
- 建库失败只记 WARN，不打断归档 run。

## 4. 自动扫描策略

建库成功后入队一次**全量扫描**，与手动扫描走同一条任务队列（`ScanJobService` +
`start_library_scan`），不另起并发通道；扫描失败重试沿用现有任务重试逻辑。

## 5. 前置修复（已完成，仅测试库）

`lux-library` 里没有 `动画` 目录，原因是镜像由归档 run 生成，而 115 侧那批 `动画` 是外部工具
整理出来的、从没走过 Lux 归档。2026-10-21 已在**测试库**（`测试库/媒体目录`，未触碰真实库）完成：

1. `动画/<年代>/` → `动画/国内|国外/<年代>/`（141 条：国内 112、国外 29）；
2. 存量年份目录 → 年代目录（电影 5 个、电视剧 8 个年份桶，22 条片；注意要把年份目录的**内容**
   合并进年代目录，不是把年份目录塞进去）；
3. 29 条 `动漫/国外` 合并回 `动画/国外`（动画/动漫合并决定）；
4. `POST /admin/archive/metadata?dry_run=false` 回填镜像；
5. 清空旧库后由自动入库重建「电影 / 电视剧 / 国内动画 / 国外动画」并各扫一次。

真实库（`影视库/媒体目录`）保持原样，等调试完成后再分批复制过来。

## 6. 验收标准

1. 清空库表后跑一次归档 run：非空分类都出现对应库，且扫描已入队。
2. 再跑一次：库数量不变（幂等）。
3. 新增非空分类（含动画地区目录）并重跑：库自动出现，且能在 web「媒体库」看到。
4. 空目录不产生库。
5. 历史数据（已有目录、无库）在进程重启后自动补齐。

单测覆盖：`auto_library::tests`（规划规则、动画国内/国外拆分、`动漫` 别名合流、
无地区回退单库、非地区子目录独立成库、幂等）+ `archive::tests::organizes_titles_into_decades`、
`archive::tests::separates_domestic_and_foreign_boards`。
